# Code of Conduct

## Our Standard

We are committed to a respectful, collaborative, and harassment-free
environment for everyone.

Examples of expected behavior:
- Give constructive technical feedback.
- Assume good intent and ask clarifying questions.
- Focus discussions on code and behavior, not people.

Examples of unacceptable behavior:
- Personal attacks, threats, or harassment
- Discriminatory or hateful language
- Publishing private information without consent

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code,
issues, and other contributions that violate this Code of Conduct.

Repeated or severe violations may result in temporary or permanent bans from
the project spaces.

## Reporting

Report conduct issues privately to project maintainers. If unsure whether
something is a violation, report it anyway so maintainers can review.
